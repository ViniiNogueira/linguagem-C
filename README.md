# Linguagem C

Este repositório reúne alguns exercícios e exemplos básicos em C, criados para praticar a sintaxe da linguagem e entender os conceitos iniciais da programação.

## Objetivo

O objetivo deste projeto é ajudar no aprendizado de C com exemplos simples de:

- entrada e saída de dados
- condicionais
- switch
- arrays e strings
- funções
- manipulação de strings

## Estrutura do projeto

```text
Linguagem-C/
├── algoritmos/
│   ├── Introducao-linguagem-C.c
│   ├── Introducao-linguagem-C-condicionais-SWITCH.c
│   ├── arrays-e-strings/
│   │   ├── Introducao-linguagem-C-arrays.c
│   │   ├── string-limpeza-buffer-linguagem-C.c
│   │   └── strings-entrada-scaf-linguagem-C.c
│   └── funcao/
│       └── Introducao-funcoes-linguagem-C.c
└── video-aulas/
```

## Conteúdo principal

### Algoritmos básicos
- Introdução à linguagem C
- Estruturas condicionais e uso de `switch`
- Exercícios com arrays e strings
- Prática com funções

### Exercícios de estudo
Esses arquivos servem como base para familiarizar-se com:

- variáveis
- tipos de dados
- operadores
- condições
- laços
- vetores
- funções
- entrada de dados via `scanf` e `gets`

## Como executar

Para compilar um arquivo em C, use o GCC:

```bash
gcc arquivo.c -o arquivo.exe
./arquivo.exe
```

## Observação

Este repositório é um material de estudo para a faculdade e contém apenas exemplos básicos para se acostumar com a sintaxe da linguagem C.

---

Feito para aprender e praticar C de forma simples e gradual.
